# Quick Finder Prototype

화장품 용기 쇼핑몰에서 캡/용기 형태를 조합해 제품을 빠르게 찾는 UI 프로토타입입니다.

## 실행

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 포함 기능

- 캡/용기 상하 조합형 카루셀 선택 (좌우 네비게이션)
- 용량/소재/넥사이즈 칩 필터
- 비호환 조합 비활성화
- 실시간 결과 수 표시 및 결과 카드 렌더링
- 부드러운 좌우 전환 애니메이션(.26s)

## 404 (NOT_FOUND) 대응

Vercel 같은 정적 호스팅에서 경로 직접 진입 시 404가 날 수 있어, 모든 경로를 `index.html`로 리라이트하도록 `vercel.json`을 추가했습니다.
또한 `404.html`에서 홈으로 즉시 이동하도록 처리했습니다.


## 이미지 정책

- 본 프로토타입의 버튼 아이콘(캡/용기)은 외부 원본 이미지를 저장/배포하지 않고, 브라우저 Canvas로 자체 생성하여 사용합니다.
- nuriplastic 사이트 이미지는 형태/구도 레퍼런스로만 참고하며, 실제 표시 자산은 자체 생성물로 대체합니다.
